# ちゅらたび: ピクセルアート方針

- ねらい: 温かく密度のある、オリジナルの旅行RPG。既存ゲームの固有キャラクター・アセットを複製しない。
- 主人公: 日本人の若い旅行者。短い暗色の髪、白いTシャツ、青いショートパンツ、歩きやすい茶色の靴、小さなリュック。
- 線: 外郭は藍がかったこげ茶 `#2B1410` の**1実ピクセル**。瞳と文字にのみ `#1A1A1A` を用いる。色数を限定し、グラデーション禁止。
- 各パーツに対して「元の顔の特徴を3個選び、32x48上で識別できるか」「靴底に統一基準線」「視点と光源が矛盾しないか」を検査する。
- 4方向は正面・背面・左・右。背面にはリュック、側面には鼻とバッグの出っ張り。左右反転しても不自然な文字やマークを入れない。
- 歩行は遊べることが必要。重心と接地位置の整合性、足の交互動作、腕の反対振りを確認する。静止画の反転・単純移動だけをアニメ完成とみなさない。
- 拡大時は nearest-neighbor、ゲーム描画は CSS `image-rendering: pixelated`、Canvas `imageSmoothingEnabled = false`。
- 注意: このSkillに含むサンプル主人公はツール動作確認用。実際の主人公の同一性を保証する元画像ではない。

## 手動視認検査 (AIが担当)
正面の目が対称か、全方向で同じ人物に見えるか、歩行ループで足の位置が飛ばないか、32px幅で服・バッグを読めるか、キャラが地面に接しているか、拡大してもにじみがないか。何度でも作り直し、自動検査だけで合格宣言しない。
