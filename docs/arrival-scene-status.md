## 今回実装した内容

- オリジナルPNG素材: 768×640ロビー、主人公・案内係・おばあ・旅人の各128×192シート、絵はがき。1セルは厳密に32×48、4方向×4フレーム。透明背景、輪郭・陰影・共通パレットを統一。
- 素材は `tools/draw-arrival.py` でネイティブ解像度に描いた座標指定のピクセル原画。ランタイムで仮の人物や家具を図形描画する方式は廃止。地形・人物・設備は完成したPNGから表示する。水泡、足元の影、移動先、方向マーカーはゲーム用演出として描画。
- 水槽の熱帯魚とサンゴ、観光案内カウンター、パンフレット、到着口、ガラス窓、待合席、観葉植物、自販機、荷物カート、2F案内を作画。
- 床の単タップ移動、幅優先探索による障害物回避、人物・設備へのタップで自動接近し会話開始。カメラ追従、目標表示による目的地確認、キーボード、長押し移動ボタン、入力解除、画面回転に対応。
- 案内を聞く→絵はがきを拾う→おばあへ返す→2階への案内を確認、のイベント進行。水槽と旅人への寄り道。完了後も散策可能。次章は実装していない。
- 旅の手帳、ブラウザ内保存、再開、二段階の記録リセット、保存失敗の説明、読み込み失敗時の再試行案内。
- Web Audioの歩行・会話・記録の効果音。音は初期OFF、明示した操作でON。非表示タブでは音を停止。
- 日本語のHTML会話、フォーカスとキーボード操作、44px操作ボタン、セーフエリア、動きを減らす設定を考慮。

## 完成判定を保留する項目

1. **iPhone実機Safari**で、アドレスバー伸縮・ノッチ・ホームインジケーター・長時間プレイ・着信/復帰・実際の効果音の聴感を未確認。WebKitのエミュレーションで代替済みとはしない。
2. 作画は全てオリジナルの実素材へ置換済みだが、「高密度で製品版として十分」という美術品質を客観テストだけで保証しない。素材図版と実画面を保存し、完成候補として区別する。
3. 実在空港の雰囲気と階層案内を参照したフィクションの縮約マップ。実寸・厳密な設備配置の再現ではない。ゲーム内ヘルプと手帳にも明示。
4. ゲーム画面の完全なスクリーンリーダー対応は未実装。会話とボタンはHTMLだが、地形と位置関係はCanvas。
